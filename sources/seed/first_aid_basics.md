# First aid basics (seed)

This is a tiny seed source used to validate the end to end pipeline in this monorepo.

## Bleeding

- Apply direct pressure to the wound with a clean cloth.
- If bleeding continues, add more cloth and keep pressure. Do not remove soaked layers.
- If severe bleeding does not stop, seek emergency help.

## Burns

- Cool the burn with cool running water for at least 10 minutes.
- Remove tight items like rings before swelling starts.
- Do not apply ice directly to a burn.
